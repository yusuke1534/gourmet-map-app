# グルメマップ（iPhone向けPWA）

添付されたロゴ画像とホーム画面イメージを元に作った静的Webアプリです。

## 公開
このフォルダの中身を GitHub Pages などの HTTPS 対応ホスティングにアップロードしてください。`index.html` がルートです。Safariで開いて「共有」→「ホーム画面に追加」でロゴのアイコンを使用できます。ローカルファイルではサービスワーカーや位置情報が正常に動作しないことがあります。

## ホットペッパーグルメAPI
ホットペッパーグルメAPIのキーはブラウザに埋め込まないでください。サーバーまたはサーバーレスAPIでキーを安全に保管し、検索を中継してください。アプリの「マイページ」で中継APIのURLを登録します。

検索時のクエリパラメータ：`keyword`, `category`, `lat`, `lng`, `order`。中継側でホットペッパーAPIの仕様に合わせて変換してください。カテゴリ名をジャンルコードに変換する処理も中継側で実装してください。

レスポンス例：`{"results":{"shop":[{"id":"J000000000","name":"店舗名","address":"東京都...","genre":{"name":"和食"},"open":"11:00〜","lat":35.0,"lng":139.0,"photo":{"pc":{"l":"https://..."}},"urls":{"pc":"https://..."}}]}}`。または `shops` 配列でも可。APIのレスポンス構造・利用条件・画像のクレジット要件は必ず公式ドキュメントで確認してください。

現時点では中継APIの実装・APIキー設定・本番接続・外部公開は未実施です。店舗情報を捏造しないため未接続時は空結果を表示します。予約履歴は外部予約サイトから取得できません。
